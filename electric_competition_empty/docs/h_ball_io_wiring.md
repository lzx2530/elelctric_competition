# H 题 IO 配置与接线

## 已确认的占用

| 信号 | 引脚 | 排针 | 保留原因 |
| --- | --- | --- | --- |
| 步进 `STEP` | PA12 | J2.32 | 平衡杆丝杠脉冲输出 |
| 步进 `DIR` | PB15 | J2.17 | 平衡杆丝杠方向输出 |
| K230 UART | PB17/PB18 | J2.18/J1.25 | 控制视觉通信 |
| I2C | PB2/PB3 | J1.9/J1.10 | OLED 与 IMU |
| 灰度阵列选通 | PA15/PA16/PB16 | J1.30/J1.29/J2.11 | 三位地址；PB16 不能复用 |
| 双轮编码器与电机 | PB0/PB1/PB4/PB6/PB13/PB20/PA28/PA31 | 多个排针 | 底盘闭环 |

## 本次复用方案

| 功能 | MCU 引脚 | LaunchPad 排针 | 原用途 | 新用途 |
| --- | --- | --- | --- | --- |
| `MODE` 按键 | PB12 | J2.19 | YAW 方向 | 切换任务模式 |
| `START` 按键 | PB8 | J2.15 | 未使用 SPI1_PICO | 启动当前任务 |
| 绝对编码器 PWM | PA8 | J1.4 | YAW `STEP` / TIMA0 CCP0 | TIMA0 组合捕获 |

不要使用 J2.16：它是 `NRST`，不是 GPIO。

## SysConfig 操作

必须在 CCS 的 SysConfig 图形界面中完成，禁止直接编辑 `empty.syscfg`。

1. 删除 `PWM_STEP_YAW` 实例，释放 `TIMA0` 和 `PA8`。
2. 在 `GPIO_TURRET` 中删除 `DIR_YAW (PB12)`；保留 `DIR_PITCH (PB15)`、`LASER_EN (PB16)` 和 `BUZZER (PB5)`。其中 `PB16` 仍供灰度阵列选通使用。
3. 新增 GPIO 组，名称为 `GPIO_BUTTONS`：
   - `MODE`：`PB12`，输入，内部上拉，使能中断，下降沿触发。
   - `START`：`PB8`，输入，内部上拉，使能中断，下降沿触发。
4. 新增 Capture 实例，名称为 `CAPTURE_ABS_PWM`：
   - 外设 `TIMA0`，CCP0 引脚 `PA8`，CC index `0`，捕获模式 `COMBINED`。
   - 时钟预分频 `32`，定时周期 `20 ms`，中断选择 `CC1_DN` 和 `ZERO`。
5. 生成代码后重新构建。固件会自动启用 `TIMA0_IRQHandler`，第一个完整 PWM 周期仅用于同步，后续每周期把高电平计数和周期计数送入 `app_ball_control_set_actuator_pwm()`。

## 接线

### 两个按键

使用常开轻触按键；按下时接地，固件使用内部上拉：

| 按键端子 A | 按键端子 B |
| --- | --- |
| `MODE`：J2.19 / PB12 | J2.20 或 J2.22 / GND |
| `START`：J2.15 / PB8 | J2.20 或 J2.22 / GND |

不要把按键接到 3.3 V；该接法会与内部上拉相反。

### 步进绝对编码器 PWM

| 编码器端 | LaunchPad 端 |
| --- | --- |
| PWM 输出 | J1.4 / PA8，经 3.3 V 电平适配后接入 |
| GND | J2.20 或 J2.22 / GND |
| 电源 | 按编码器铭牌由独立稳压电源供电 |

`PA8` 不能直接承受 5 V 或更高电平：

- 编码器为 3.3 V 推挽输出：可直接接 PA8。
- 编码器为 5 V 推挽输出：用单向 5 V 到 3.3 V 电平转换器；低频 PWM 也可用 `20 kΩ` 上臂、`39 kΩ` 下臂的分压（输出约 3.3 V）。
- 编码器为 NPN 开集电极：编码器侧不得再上拉到 5 V；在 PA8 侧用 `4.7 kΩ` 上拉到 LaunchPad 3.3 V。
- 编码器为 12/24 V、差分或未知输出：先用光耦/专用接收器完成 3.3 V 逻辑转换，禁止直接连接。

无论哪种方式，编码器电源地与 LaunchPad GND 必须共地；先用示波器确认 PA8 波形范围为 `0..3.3 V` 后再上电运行。
